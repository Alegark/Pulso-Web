# Copias locales: incremento de lectura y exportación

El incremento en desarrollo permite consultar un inventario, verificar una copia individual, solicitar persistencia al navegador y preparar un audio de hasta 8 MiB para descargarlo con una segunda acción. No ofrece retirada ni borrado. Los archivos kept y los datos de propiedad desconocida se conservan.

La consulta es explícita y paginada, hasta 50 filas por página. Un inventario nuevo invalida las referencias opacas anteriores. Se muestran por separado bytes declarados, bytes observados, presencia y verificación de integridad. Parciales, ausencia y resultados desconocidos no se convierten en cero ni en disponibilidad confirmada. Los contadores pertenecen al snapshot consultado; la cola es la guardada, no un registro de lectores activos. La identidad/incarnation se mantiene desconocida y este inventario no concede permisos destructivos.

El worker limita datos retenidos y materialización, calcula SHA-256 fuera del hilo de interacción y comparte el lector de assets. El coste transitorio del clon nativo de un registro IDB no queda acotado por el presupuesto de metadata retenida. El worker de lectura no crea ni migra un schema. La ventana posee sólo sus URLs de exportación y las libera al cerrar, reemplazar, refrescar o cambiar de control/lifecycle; una URL ya entregada no permite retirar bytes que el navegador haya recibido.

Preparar y pulsar el enlace no demuestran que se guardó una copia externa. La persistencia se solicita desde un gesto, puede denegarse y no garantiza protección frente a purgas. Uso y cuota estimados corresponden a todo el origen.
