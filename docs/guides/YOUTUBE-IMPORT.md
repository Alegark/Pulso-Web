# Importar playlists de YouTube

Configuración → Conexiones → «Importar playlist de Spotify o YouTube» acepta enlaces de Spotify, enlaces de YouTube con `list=` e IDs sueltos de playlists de YouTube. La importación es manual y nunca se inicia al entrar o iniciar sesión.

- `GET /api/youtube-playlist?list=<id>` (Worker, `deployment/cloudflare/youtube-playlist.mjs`) lee títulos y canal con la API oficial YouTube Data v3. Exige sesión autenticada de Pulso, origen mismo sitio y límites por cuenta e IP; una petición anónima responde 401. El Worker requiere el secret de API `YOUTUBE_API_KEY` (Google Cloud → YouTube Data API v3); nunca lo guarda en el cliente ni lo incluye en respuestas. Sin configuración responde 503 y la UI muestra un mensaje claro.
- `src/library/youtube-playlist.ts` convierte cada video en título + artista: canal «X - Topic» = artista; «Artista - Título» se separa; se quitan «Official Video», «Lyric Video», hashtags; shorts, mixes y similares se descartan. Una subida de fans con el canal como artista simplemente no aparecerá en el bot.
- `src/playlists/youtube-import.ts` guarda la playlist en Biblioteca igual que el importador de Spotify (misma transacción, límites y membresía). Reutiliza canciones ya presentes con el mismo título y artista, prefiriendo una copia disponible. Reimportar la misma lista actualiza solo su playlist vinculada; una playlist manual con el mismo nombre permanece intacta.
- La importación guarda o actualiza la playlist sin descargar audio. El resultado resume canciones, fichas reutilizadas, copias disponibles, canciones pendientes, videos ignorados y truncamiento; incluye «Abrir en Biblioteca» y, si faltan copias, el botón manual opcional «Descargar faltantes (N)».

Pruebas: `tests/unit/youtube-playlist.test.ts`, `tests/server/youtube-playlist.test.mjs` (incluye Worker en Miniflare) y `tests/integration/check-youtube-import.mjs` en Chromium y WebKit. Las pruebas usan API, cuentas y canciones sintéticas; no generan tráfico real de Telegram, YouTube ni bots.
