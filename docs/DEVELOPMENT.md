# Desarrollo de Pulso Web

Destino autorizado: `/data/home/Proyectos/Pulso-Web`. Objetivo completo activo en `odd/tasks/P0-W.md`; implementación actual: piloto T1–T3, preflight público T4 y fase web de importación/biblioteca/playlists. SPEC/README originales y enlaces preservados.

Requisitos comprobados: Node 22.23.3, npm 10.9.9, Linux x64. `npm ci` instala el lockfile.

- `npm run typecheck`: TypeScript estricto del producto.
- `npm run lint`: TypeScript con símbolos/parámetros sin usar; no equivale a ESLint.
- `npm run test:unit`: controlador real con medio simulado y rangos HTTP; no demuestra audibilidad.
- `npm run build`: bundle de producción + `dist/sw.js`, shell por hash, sin skipWaiting.
- `npm run test:browser`: construye runners reales de IDB y SDK en `.local/browser-tests`. Construirlos no es ejecutarlos. Servirlos SOLO loopback: `npx --no-install vite preview --host 127.0.0.1 --port 4174 --strictPort --outDir .local/browser-tests`. Abrir `/tests/browser/index.html` y `/tests/browser/sdk.html` con preview T3, comprobar `window.pulsoTests`/`window.pulsoSdk`; requieren PASS.
- Producto local: `npx --no-install vite preview --host 127.0.0.1 --port 4173 --strictPort`. No publicar el puerto.
- `python3 scripts/generate-fixtures.py` y `node scripts/encode-fixtures.mjs`: generan fixtures propias WAV/MP3/AAC-LC. El encoder FFmpeg GPLv3 es herramienta de desarrollo Linux fijada, utilizada solo con tonos propios; no entra al bundle del producto. Binario antiguo: no procesar archivos ajenos con él. Preservar avisos si se redistribuye la herramienta. Los audios generados no incorporan código del encoder.

No ejecutarlo contra almacenamiento del propietario ni atribuir sus resultados al iPhone. No requiere el enlace HTTPS privado.

Cancelación de lote contra commit: tras `npm run build`, ejecutar `INSTABOX_HEADLESS=1 node tests/integration/check-import-cancel.mjs`. Abre el producto/worker reales en loopback efímero y un contexto limpio, selecciona dos fixtures propias y pulsa Cancelar justo cuando llega el primer resultado confirmado. El perfil se elimina al terminar. No prueba iPhone ni avance musical audible.

`INSTABOX_HEADLESS=1 node tests/integration/check-import-recovery.mjs` inyecta pérdida del acuse de cierre en el worker, confirma bloqueo del resto del lote, reabre y recupera desde UI mediante worker de verificación. También comprueba que revisar un job legacy conserva bytes y estado sin fingir complete. Solo fixtures propias y loopback efímero.

Recuperación: el job y su prueba de propiedad se crean antes de los bytes. Sellado OPFS/IDB se verifica por relectura; publicación breve confirma manifiesto/relaciones/job. Registros legacy o inválidos requieren revisión expresa: se conservan sin asignarles owner ni eliminarlos. La recuperación con hash se ejecuta en worker, sin recrear el motor de audio.

La consulta local-assets-v1 comprueba capacidades del controller antes de pedir tickets; si no responde, usa el modo Blob acotado existente y solicita update normal, sin skipWaiting. Para aplicar la versión nueva, cerrar las otras pestañas de Pulso y reabrir; no se fuerza takeover ni activación.

Objetos fuera del límite quedan no reparables por esa API, conservados. No se promete defensa frente a JavaScript hostil del mismo origen que eluda locks/revisiones.
