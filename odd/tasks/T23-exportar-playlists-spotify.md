# T23 · Exportar listados públicos de playlists Spotify

Fecha: 2026-11-17. Estado: revisión root aprobada y publicación efectuada; cierre funcional bloqueado por fetch de Spotify desde Cloudflare (502/network). Git entregado en rama `feat/spotify-playlist-export` y PR #3. No cierra P0-W ni aceptación física.

## Objetivo y autorización

Petición explícita: sección «Exportar playlists» en Configuración que explique Spotify → Compartir → Copiar enlace → pegar → Leer playlist, sin conectar cuenta Spotify. Preview de nombre/conteo y descargas CSV/TXT por gesto. Sólo listado; no importar a Pulso, descargar audio ni utilizar Telegram. USD 0. Autorizada una lectura pública real para prueba; conservar únicamente agregados y huellas de código, nunca el listado personal ni sesiones. La publicación autorizada corresponde al cierre posterior a revisión, fuera de esta unidad de implementación.

## Diseño y fronteras

- Componente independiente en General, después de Almacenamiento. Formulario accesible, input de 16px, controles de 44px, texto con wrap y estados anunciados. Skills mobile-native/emil-design-eng aplicadas. Montaje sólo mientras Configuración/General están visibles; abort al desmontar, editar o volver a leer; resultado anterior eliminado antes de cambiar URL. No accede al motor musical.
- Cliente acepta sólo HTTPS open.spotify.com/playlist/ID base62 de 22 caracteres, sin credenciales/puerto, y descarta tracking. Endpoint GET same-origin `/api/spotify-playlist/<id>`; no frontend cross-origin. Worker valida ruta/ID/query/origen y construye exclusivamente `https://open.spotify.com/embed/playlist/<id>`, sin reenviar cabeceras del visitante, cookies o tokens; redirects error, timeout 8s, respuesta no-store, sin persistencia.
- Límite HTML 1MiB medido en streaming, máximo 1000 filas fuente para aceptar formato y 100 entradas leídas/exportables, campos de hasta 500 caracteres; duración válida hasta un día o desconocida. Parse JSON del único script __NEXT_DATA__, sin ejecutar HTML/JS. Allowlist title/subtitle/duration y enlaces reconstruidos de URI track válido. No se conserva/solicita audioPreview ni audio.
- Episodios/locales/entradas sin URI track se cuentan como omitidos. Pistas no disponibles pueden exportar metadata sin afirmar reproducibilidad. Fallo de acceso/formato informa «No se pudo leer», sin inventar que no existe. Completitud desconocida cuando falta total; no se infiere por 41. Mensaje de límite100 cuando se alcanza. Advertencia breve de que la lectura pública puede cambiar.
- CSV con BOM, CRLF, todas las celdas entrecomilladas, comillas escapadas e inicios de fórmula neutralizados; TXT conserva texto de metadata y añade contexto de conteos/completitud. Nombre de descarga fijo, sin usar el nombre remoto como ruta.
- Worker añade una ruta y un import; wrangler sólo añade run_worker_first para esa ruta. CSP, bindings y configuración existentes preservados. SW sólo cachea su lista de shell, no esta API.
